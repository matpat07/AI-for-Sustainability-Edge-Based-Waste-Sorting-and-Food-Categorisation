## 1. Operational Modes Comparison Matrix

All three execution modes were run sequentially across the entire 613-image held-out test split:

| Metric | MAX Mode (All Cores) | BALANCED Mode (2 Cores) ⭐️ | ECO Mode (1 Core) |
| :--- | :---: | :---: | :---: |
| **CLI Command** | `./run_edge.sh eval --max` | `./run_edge.sh eval --balanced` | `./run_edge.sh eval --eco` |
| **Cores Bound** | **4 Cores** (unconstrained) | **2 Cores** (`taskset -c 0,1`) | **1 Core** (`taskset -c 0`) |
| **Max Pi CPU Cap** | **100%** (all 4 cores busy) | **50%** (cores 2 & 3 100% idle) | **25%** (cores 1, 2, 3 idle) |
| **Frame Pacing Delay** | `0 ms` (back-to-back) | `50 ms` sleep | `100 ms` sleep |
| **Process Niceness** | `10` | `10` | `10` |
| **Average Latency** | **78.15 ms** | **93.73 ms** | **162.94 ms** |
| **Median Latency** | **76.00 ms** | **93.28 ms** | **162.53 ms** |
| **95th %-tile Latency** | **86.73 ms** | **96.54 ms** | **164.63 ms** |
| **Min / Max Latency** | 71.49 ms / 124.20 ms | 92.75 ms / 150.36 ms | 161.96 ms / 218.85 ms |
| **Inference Throughput** | **12.8 FPS** | **10.7 FPS** | **6.1 FPS** |
| **Total Test Split Time**| **62.7 s** | **72.2 s** | **114.6 s** |
| **Peak RAM Footprint** | **73.63 MB** | **76.12 MB** | **73.58 MB** |
| **Estimated Avg Power** | **~5.3 W** (1060 mA @ 5V) | **~3.4 W** (680 mA @ 5V) | **~2.6 W** (520 mA @ 5V) |
| **Power Savings vs MAX**| Baseline (0%) | **~36% Power Reduction** | **~51% Power Reduction** |

| **Thermal Behavior** | +6.0°C rise in ~6s (Hot) | Gradual rise / Cool | Barely above idle |

> ⭐️ **Recommendation:** **`BALANCED` mode** provides the optimal edge compromise. Latency only increases by **~15.6 ms** compared to unconstrained mode, while cutting peak CPU load in half and keeping cores 2 & 3 free for camera ingestion and network operations.

## 3. Production Deployment Guide

On the Raspberry Pi:
```bash
cd ~/waste_edge_ai

# 1. Run Balanced Mode (Recommended for continuous camera sorting)
./run_edge.sh eval --balanced

# 2. Run Eco Mode (Recommended for solar/battery-powered bins)
./run_edge.sh eval --eco

# 3. Single-Image Inference
./run_edge.sh infer "dataset/waste_4class/plastic/pet (105).jpg"
```
