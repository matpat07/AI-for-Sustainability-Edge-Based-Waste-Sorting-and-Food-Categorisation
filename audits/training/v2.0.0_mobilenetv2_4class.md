## 1. Executive Summary

This audit documents the fine-tuning of a lightweight **MobileNetV2** transfer learning model targeting **4 primary societal waste categories**: `biodegradable`, `glass`, `metal`, and `plastic`.

The model achieved an out-of-sample **95.27% validation accuracy** across 613 held-out test images, trained locally on an **Intel Core Ultra 5 125H** processor using multi-threaded AVX2/oneDNN acceleration. The model was compiled and lowered directly to **ExecuTorch (`.pte`)** using the **XNNPACK partitioner** for real-time edge execution.

- **Dataset Root**: `dataset/waste_4class`
- **Total Validated Samples**: 4,085 images

## 3. Training Architecture & Hyperparameters

- **Base Architecture**: `torchvision.models.mobilenet_v2(weights=MobileNet_V2_Weights.DEFAULT)`
- **Freezing Strategy**:
  - `model.features[:-2]` frozen (preserves low-level ImageNet feature representations).
  - Top 2 inverted residual blocks (`model.features[-2:]`) unfrozen for domain adaptation.
  - Linear classifier head replaced: `nn.Linear(1280, 4)`.
- **Optimizer**: AdamW (`lr=1e-3`, `weight_decay=1e-4`)
- **Scheduler**: CosineAnnealingLR (`T_max=4`)
- **Loss Function**: CrossEntropyLoss
- **Batch Size**: 64
- **Epochs**: 4
